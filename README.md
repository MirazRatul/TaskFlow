# TaskFlow Pro

A medium-sized vanilla HTML, CSS, and JavaScript project.

## Features

- Add tasks with title, due date, priority, and status
- Filter tasks by status
- Search tasks
- Sort by newest, oldest, priority, or due date
- Update task status
- Delete tasks
- Dashboard statistics
- Dark/light mode
- Data saved in localStorage
- Responsive design

## How to Run

Open `index.html` in your browser.

No installation needed.
